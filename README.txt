LUXURY ESTATE — демонстрационный сайт элитного агентства недвижимости

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для публикации загрузите все три файла на любой статический хостинг.

Что внутри:
- index.html — структура и контент
- style.css — тёмный премиальный дизайн, адаптивность, анимации
- script.js — фильтры каталога, мобильное меню, появление блоков и форма

Важно:
- Фотографии загружаются по URL с Unsplash и требуют подключения к интернету.
- Объекты, цены, телефон и контакты демонстрационные.
- Форма пока работает локально и не отправляет данные. Для реальных заявок подключите backend/CRM.
- Перед запуском замените демонстрационные контакты, объекты, цены и добавьте политику конфиденциальности.
